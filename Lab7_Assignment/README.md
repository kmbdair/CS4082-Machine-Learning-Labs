# Lab 7 Assignment

This folder contains the submission for Lab 7 Assignment.

## Description

This assignment focuses on building a model comparison function for machine learning models.

The function trains multiple models, makes predictions, evaluates their performance, and returns a structured output containing accuracy, precision, recall, and F1-score.

## Tasks

- Build a model comparison function
- Train each model
- Predict on the test set
- Evaluate model performance
- Return the results in a DataFrame
- Solve Exercise 2
- Solve Exercise 3
